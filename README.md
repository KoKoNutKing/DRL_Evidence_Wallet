## Basic Git conventions

- Use a branch for each small task, such as `docs/proposal` or `wireframes/main-flow`.
- Write short, descriptive commits; stage relevant files and review the diff first.
- Update from the main branch before working and coordinate changes to shared files.
- Ask another member to review before merging when working as a team; update AI-LOG when using AI.
- Do not commit passwords, tokens, real environment files, or submission ZIPs.
